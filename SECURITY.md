# Security policy

## Supported versions

Security fixes are released for the latest major version.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub private vulnerability reporting for this repository or email `security@paymos.io` with:

- the affected version;
- reproduction steps or a proof of concept;
- the expected impact;
- any suggested remediation.

We will acknowledge a complete report within two business days and coordinate disclosure after a fix is available.

Never include live Paymos API keys, API secrets, webhook secrets, customer data, or wallet credentials in a report.
